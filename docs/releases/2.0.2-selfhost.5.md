# Logseq 2.0.2-selfhost.5

## Changes

- Add literature CLI commands to list, search, inspect, import, and update bibliography records, and attach PDFs.
- Support JSON input from files or stdin, structured JSON/EDN output, dry-run previews, and stable Paper and Asset UUIDs for scripts and agents.
- Report PDF availability, search truncation, partial failures, and active sync repair without hiding unsuccessful operations.
- Validate bibliography imports before creating a destination page, keeping dry-run and rejected imports free of page-creation side effects.

## Updating

- Users on 2.0.1-selfhost.6 should download and install the package for their platform manually.
