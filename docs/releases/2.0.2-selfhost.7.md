# Logseq 2.0.2-selfhost.7

## Changes

- Fix inherited tag dependencies and task and priority queries.
- Fix page creation and UUID handling during undo and redo, including namespace pages.
- Improve Markdown imports and exports, attachment indexing, and PDF annotation references.
- Fix packaged CLI import and page rename behavior.
- Fix favorites and recent pages becoming unavailable after switching graphs, and prevent delayed page visits from being recorded in another graph.
- Restore authentication before accessing encryption keys and offer sign-in when the session is missing.
- Keep device settings, including fonts, colors, and the sync server, when signing out.
- Enforce configured authentication for the desktop HTTP API. Scripts and integrations using that API must include the configured bearer token.

## Updating

- Users on 2.0.1-selfhost.6 should download and install the package for their platform manually.
