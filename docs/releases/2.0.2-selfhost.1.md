# Logseq 2.0.2-selfhost.1

This version incorporates the official Logseq 2.0.2 fixes while retaining the self-hosted features.

## Changes

- Share a custom display name and uploaded avatar across graphs and devices on the same self-hosted service.
- Show names consistently in collaboration avatars and tooltips.
- Keep favorites and recent visits private to your account on each graph, with live cross-device synchronization and offline edits on the same self-hosted service. Existing navigation is carried over automatically; the server and clients need this update.
- Set font family and size separately for notes/editor text and the application interface, including installed fonts and independent resets.
- Support graph-scoped personal access tokens and encrypted REST API writes on the self-hosted service.
- Include upstream fixes for synchronization timestamps, editor save/click races, desktop scrolling clicks, imports, journal dates, repeating dates, and the first edit of export.css.
- Remove finite future-version restrictions from signed update verification while retaining signature, archive, and target-identity checks.

## Updating

- New clients use the standard electron-updater GitHub Release update flow.
- Clients on 2.0.1-selfhost.6 need the genuine 2.0.1-selfhost.7 transition release before this version. Both steps use the normal download, installation confirmation, and restart flow; they are not a single silent installation.
- The transition supports macOS x64/arm64, Windows x64, and Linux x64/arm64. Windows arm64 clients on .6 require a manual first installation.
- Availability of the automatic transition depends on publication and activation of the transition release. Local development or a Draft alone does not enable it.
