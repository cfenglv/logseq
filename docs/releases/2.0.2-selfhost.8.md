# Logseq 2.0.2-selfhost.8

## Changes

- Fix inherited templates duplicating unchanged blocks when a child template was copied from its parent. Keep the child template's additions and inherited properties.
- Recover valid references when replaying offline edits and keep remotely deleted references removed. Show when an edit could not be replayed.
- Improve copying and moving existing attachments and clear download progress when a transfer finishes or fails.
- Open desktop links directly on startup and recover when the last-opened graph has been removed. Keep recent pages focused on visits in the main view.
- Improve narrow PDF layouts and add Tab completion to the slash menu.
- Align CLI queries and reference handling with the desktop app and report import and argument errors more clearly.

## Updating

- Users on 2.0.1-selfhost.6 should download and install the package for their platform manually.
