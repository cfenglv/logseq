# Logseq Self-hosted RTC 2.0.1-selfhost.1

This is the first self-hosted desktop release based on upstream Logseq 2.0.1.

## Changes

- Added support for a configurable self-hosted DB Sync / RTC server.
- Added authentication refresh handling required by a custom Worker endpoint.
- Routed desktop HTTP and WebSocket traffic through the system proxy on Windows, macOS, and Linux.
- Added lifecycle handling for the packaged `db-worker-node` runtime.
- Fixed encryption initialization against a self-hosted sync endpoint.
- Added desktop packages for macOS, Windows, and Linux on x64 and ARM64.

## Known limitations

- Self-hosted RTC remains experimental. Keep independent backups of important data.
- Windows builds are unsigned and may trigger SmartScreen.
- macOS builds are not notarized with an Apple Developer ID and may trigger Gatekeeper.
- Every collaborator must configure the same Sync Server URL and use a compatible client version.
