# Logseq 2.0.1-selfhost.6 — Official Architecture Rebuild

This is the reissued Selfhost `.6`, rebuilt from the frozen official-architecture source commit `625516e5fc69d8b348464119f2da625bd313d2f4`.

## Distribution boundary

- First install is a controlled manual download from this release line.
- This release does not update or reuse any withdrawn `.6` asset or legacy `latest-*` channel.
- macOS artifacts are ad-hoc signed and not notarized.
- Windows and Linux artifacts are unsigned.
- Every archive has a protected-project Ed25519 descriptor binding the exact source, version, platform/architecture, archive size and hashes, target-build manifest, and immutable object identity.
- Automatic same-version transition from the withdrawn `.6` is intentionally unsupported.

## Supported desktop artifacts

- macOS arm64
- macOS x64
- Windows x64
- Linux x64
- Linux arm64

The archive filenames include both the frozen source prefix and archive digest prefix. Do not rename or replace published assets.
