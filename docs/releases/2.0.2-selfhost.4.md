# Logseq 2.0.2-selfhost.4

## Changes

- Keep workspace navigation available when a page fails, with recovery actions and diagnostics grouped in separate tabs.
- Add application and graph sync log shortcuts to recovery and sync details, plus an application-log shortcut in Help.
- Show progress and results for rebuilding the search index, exporting a graph backup, and restarting the app.
- Prevent profile avatars from opening the image-saving context menu.

## Updating

- Users on 2.0.1-selfhost.6 should download and install the package for their platform manually.
