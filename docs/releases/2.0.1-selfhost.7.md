# Logseq 2.0.1-selfhost.7

This release keeps the Selfhost `.6` architecture and applies a narrow set of desktop and editor fixes.

## User-visible fixes

- Keep the current page covered until deletion navigation settles, avoiding a stale-page flash after a left-click delete.
- Keep Node embed Delete and Cut scoped to the placeholder while preserving editing inside embedded pages.
- Refresh node-reference labels, page-reference search results, tag icons, sidebar language, and settings language correctly.
- Harden editor autocomplete, journal focus, page-title Enter, repeated Backspace, legacy favorites import, query rendering, and Markdown Task export behavior.
- Isolate MCP server state per session and honor uppercase proxy environment variables.

## Update boundary

- Advance the isolated update line from `.7` to the synthetic `.8` forward-update target.
- Add Windows arm64 to the signed target matrix.
- Keep release promotion fail-closed: immutable archives are never overwritten, and channel pointers use compare-before-write recovery.

This release does not add a graph schema, protocol, or database migration.
